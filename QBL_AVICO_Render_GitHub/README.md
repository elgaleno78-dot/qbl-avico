# QBL Obstétrico AVICO®

Aplicación web responsive/PWA para apoyo al registro de hemorragia obstétrica.

## Publicación en Render
- Tipo: Static Site
- Branch: `main`
- Build Command: dejar vacío
- Publish Directory: `.`

## Uso
La aplicación inicia sin datos clínicos precargados. Los cálculos se realizan localmente en el navegador y el Service Worker permite funcionamiento PWA/offline tras la primera carga.

## Nota clínica
Herramienta de apoyo y prototipo sujeto a validación clínica/local. No sustituye juicio clínico, protocolos institucionales ni medición directa del volumen circulante.
