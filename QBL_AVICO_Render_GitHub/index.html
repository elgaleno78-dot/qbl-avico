WHO 2025: para HPP posparto, el criterio de acción temprana es pérdida objetivamente medida ≥300 mL con cualquier signo hemodinámico anormal (FC >100, índice de choque >1, TAS <100 o TAD <60), o pérdida objetivamente medida ≥500 mL, lo que ocurra primero dentro de las primeras 24 h. La app usa sólo QBL objetivamente medido para este criterio.

3. Sangrado pesado / cuantificado

Registra cada compresa, gasa, campo u otro material uno por uno. Cada medición se suma automáticamente al QBL acumulado. Para textiles: 1 g ≈ 1 mL de sangre.

Flujo rápido: selecciona material → indica cantidad → peso seco por unidad → peso húmedo total → Agregar medición. Puedes borrar una medición si se capturó por error.

7. Pacientes guardadas y exportación

Privacidad: los registros se guardan únicamente en el almacenamiento local de este navegador/dispositivo. No se envían a un servidor. Para uso clínico institucional se requiere validar seguridad, respaldo, control de acceso y normativa de datos personales.

8. Compartir / instalar QBL AVICO

El QR se genera con la dirección actual de la aplicación. Cuando esté publicada en una URL HTTPS, al escanearlo abrirá directamente QBL AVICO.

El QR apunta a la URL pública actual. Si el dispositivo admite compartir, el botón Compartir abre la hoja nativa de iPhone/Android; también puedes copiar el enlace.
